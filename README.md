# DICE JUMPER
<p>A puzzle minigame designed for mobile devices and PC.<br>
  It consists of a die that can be moved to a square that is the same distance away as the number on its top face. But keep in mind, jumping to a square will rotate the die 90º in that direction, changing the number.<br>
  Check it out on https://guillermolmr.itch.io/dice-jumper<br>⚠️IMPORTANT⚠️ On mobile, play in landscape mode. Not portrait.</p>
